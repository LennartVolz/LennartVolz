# 💫 About Me

I’m a Computer Science student specializing in **IT Security**, with a strong interest in **cybersecurity, network security, AI security, and security automation**.

My work focuses on combining traditional security technologies with modern AI-based approaches. I enjoy building practical tools that connect **network telemetry, security analytics, APIs, and AI agents** to make security data more accessible, actionable, and automation-ready.

### 🔐 Areas of Interest

* 🔐 IT & Network Security
* 🤖 AI Security & Local LLMs
* 🌐 Network Monitoring & Security Analytics
* 🛡️ Cisco Security Technologies
* 🔌 API & MCP Development
* 🐳 Docker & Containerization
* 🐍 Python Development
* 🐧 Linux & Open Source
* ⚙️ Security Automation & DevSecOps

### 🚀 Current Projects

One of my main projects is a **Cisco Secure Network Analytics MCP Server**, integrating Cisco Secure Network Analytics with the **Model Context Protocol (MCP)**.

The project enables AI systems to query:

* 🌐 Network flows
* 🚨 Security events
* 💻 Asset information

This allows AI agents to use network telemetry for **security analysis, investigation, and automation**.

A particular focus of my work is making security telemetry **LLM-ready**. Instead of passing huge amounts of raw network data to an AI model, I develop aggregation and preprocessing techniques that reduce complex telemetry into compact, structured, and meaningful information.

I’m especially interested in the intersection of:

**Cybersecurity × Network Analytics × AI × Automation**
